#  StudyBuild – Project 02: Customer Behavior Analysis

In this project, you will work as a **Junior Data Analyst** and solve a real-world business problem using Python.

## 📁 Repository Structure

```
dataset/
submissions/
README.md
LICENSE
```

- **dataset/** → Project dataset
- **submissions/** → Participants' solutions

Each participant should create a folder using their GitHub username.

Example:

```
submissions/
└── your-github-username/
    ├── project02_analysis.ipynb
    ├── README.md
    └── charts/
```
